# 星マート ─ 雨夜の街角

一个可以自由拖拽、旋转、缩放观看的三渲二雨夜便利店街角微缩模型。

## 直接观看

双击打开 **`hoshimart-rainy-corner.html`**。这是单文件版本，Three.js 与所有程序化贴图都已内联，不需要启动服务器，也不需要联网。

开发版（便于改代码）：

```bash
cd rain-convenience
python3 -m http.server 8137
# 打开 http://127.0.0.1:8137/
```

## 操作

- 拖拽：旋转视角
- 滚轮 / 双指：缩放
- 无任何 UI 控件，无人物

## 场景内容

- 完整正方形多层收藏底座，黄铜包边与铭牌，底部毛毡与接触阴影
- 日式便利店：深绿招牌、转角灯箱、玻璃橱窗、自动门、雨棚、门口地垫、ATM、自动贩卖机、自行车、伞架、垃圾桶、邮筒、路锥、公告栏、盆栽
- 店内：饮料冷柜、便当/饭团墙、双列货架、杂志架、立式冰淇淋柜、收银台、咖啡机、关东煮、香烟柜、储物柜、海报、灯箱、地面导视、员工门
- 街角：斑马线、停止线、停车位、排水沟、井盖、盲道、护栏、电线杆、电线、路牌、路灯、行人/车辆信号灯、小巷、空调外机
- 动效：持续降雨、檐口滴水、溅水环、积水波纹、玻璃雨痕、招牌轻微闪烁、自动门周期开合、屋顶风扇、关东煮/咖啡蒸汽、信号灯周期变化
- 美术：Toon 材质 + 轮廓线、湿路面平面反射、暖店内光 vs 冷雨夜、Bloom、雾、背景渐变

## 文件

- `index.html` — 开发版入口
- `src/main.js` — 渲染器、相机、灯光、后期、循环
- `src/world.js` — 底座、街道、建筑、电线、信号灯
- `src/store.js` — 便利店内外
- `src/props.js` — 街道道具与小橘猫
- `src/rain.js` — 雨、溅水、檐滴、水雾
- `src/water.js` — 平面反射与湿地面
- `src/textures.js` — 全部程序化 Canvas 贴图
- `src/core.js` — toon/flat 材质、几何、轮廓线
- `src/layout.js` — 尺寸与坐标
- `hoshimart-rainy-corner.html` — 可直接打开的单文件成品
- `tools/build-standalone.sh` — 重新生成单文件成品

## 说明

使用 Three.js r160（vendor 内已附）。所有贴图由 Canvas 程序化绘制，无外部图片依赖。
